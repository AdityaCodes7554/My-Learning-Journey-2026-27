# 🧮 Python Calculator

A simple Python Calculator project developed as part of my programming learning journey.

## 🚀 About the Project

This project is designed to perform basic mathematical calculations using Python.

It is one of my practical projects while learning Python programming.

## ✨ Features

- Addition
- Subtraction
- Multiplication
- Division
- User-friendly input
- Basic error handling

## 🛠️ Technologies Used

- Python 3

## ▶️ How to Run

1. Clone this repository.
2. Open the Python-Calculator folder.
3. Open the terminal.
4. Run the following command:

```bash
python calculator.py
```
